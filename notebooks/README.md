# Jupyter Notebooks

This directory contains the Jupyter Notebook files used throughout the development and experimentation of the lung disease classification research project.

## Notebooks

### 1. Densenet_Implementation_Updated (1).ipynb

This notebook contains the initial implementation of the DenseNet-121 model without transfer learning. It represents the earlier stage of the project, before incorporating pretrained weights.

### 2. Densenet_Implementation_Full_TransferLearning.ipynb

This notebook contains the updated implementation using transfer learning with a pretrained DenseNet-121 model. It includes experiments conducted using original chest X-ray images, Histogram Equalization and CLAHE.

## Purpose

These notebooks document the development of the classification model and the experiments conducted to investigate the effect of image enhancement on lung disease classification performance.
