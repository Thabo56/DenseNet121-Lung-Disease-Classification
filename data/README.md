# Dataset

## Overview

This project uses a chest X-ray dataset containing 12,643 images across four lung disease categories.

## Dataset Distribution

| Class | Number of Images |
|---|---:|
| COVID-19 | 3,159 |
| NORMAL | 3,161 |
| PNEUMONIA | 3,162 |
| TUBERCULOSIS | 3,161 |
| **Total** | **12,643** |

## Dataset Splitting

The dataset was divided into:

- Training: 65%
- Validation: 20%
- Testing: 15%
